# MurderBoards


An internet mystery game where the player is trapped in front of a computer and has to make it out. 
Playable basics for now. A little wonky because godot wasn't working right.
There will be no more updates to this. I will probably make another project instead because the new changes crash the project.


My first ever game made by myself (without a team). Probably also the largest one I've made (literally crashed my computer).

Made in Godot (with GDscript)


To play the game, simply go through each file in the computer to look for clues. 
Enter the final answer in the terminal to make it out. 
There are a few traps in the process, so be awware of what you enter.

I learned how to make windows and scrolling containers in godot with this project.
